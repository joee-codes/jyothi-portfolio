# Jyothi L — Portfolio

A responsive React + Vite personal portfolio featuring GSAP scroll reveals, a personal portrait hero, project cards, skill filters, and contact links.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Personal assets
- `public/jyothi-profile.png` — portrait used in the hero section.
- `public/Jyothi-L-Resume.pdf` — resume linked from the hero section.

## Before publishing
- Check the resume PDF and replace it whenever your resume changes.
- Review contact links and project repositories.
- FinInsight and ChurnLens GitHub links are connected; IntelliFix is presented without a repository link because one was not provided in the resume.
